## Как вносить изменения

1. Маленькая точная правка. Без новых зависимостей и фреймворков (единственная зависимость — `pg`).
2. `APP_VERSION` в `public/ui.js` +1, строка сверху в `CHANGELOG.md`.
3. `npm test` → должно быть «✓ Всё в порядке». Красный — не пушить.
4. Коммит в `main` → push в GitHub. Деплой — см. ниже.
5. **Правит один.** Пока сайт на Replit — агент Replit не запускается, владелец в Replit жмёт только Git → ↻ (обновить) → Sync Changes → Republish (просто Pull без ↻ может ничего не подтянуть).

Секреты (значения никогда не в код, логи, git): `SITE_KEY` (12 символов), `ADMIN_PIN`, `DATABASE_URL` (только Replit).

## План переезда (делать по шагам, у владельца спрашивать подтверждение)

**A. Код (в репозитории):**
1. `GET /api/export` — только `anton`: JSON со ВСЕМИ записями хранилища (`state.json`, `users.json`, `sessions.json`, `photo:*`, `backup:*`). Пункт «Скачать полную копию» в «Ещё» у Антона (RU/TR).
2. `scripts/import.js <файл>` — заливает выгрузку в текущее хранилище (файлы `DATA_DIR` или PG). В непустое — только с `--force`.
3. Баг синхронизации: `srvPull`/`srvStartPoll` в `public/ui.js` обновляют state, но не перерисовывают открытую шторку/форму; после `odo_fix`/`car_reset` у другого телефона остаются старые данные. Исправить без затирания введённого водителем; при закрытии шторки — перерисовать фон.
4. Убрать мусор шаблона Replit: `lib/`, `pnpm-*`, `tsconfig*`, `scripts/src`, `scripts/package.json` (проверить, что `npm test` и сервер не зависят). `.gitignore`: + `initial-pins.txt`.
5. `deploy/docker`: добавить `SITE_KEY`, `ADMIN_PIN` через `.env`; хранилище — файлы в `./data` (PG не нужен). Caddy уже даёт HTTPS.
6. Автодеплой: push в `main` → сервер обновляется (GitHub Actions по SSH или self-hosted runner) — выбрать с владельцем.

**B. Сервер:**
1. Docker + compose, клон репозитория, `.env` с секретами (владелец вводит сам).
2. Тест на поддомене `new.autozxc.app` (A-запись → IP сервера). **Не по голому IP:** `.app` — только HTTPS (HSTS preload), cookie `Secure`.
3. Перенос копии данных (export с Replit → import), проверка с телефонов.

**C. Переключение (~5 мин):**
1. За сутки снизить TTL A-записи `autozxc.app` до 300.
2. В день X: свежий export с Replit → import на сервер → A-запись `autozxc.app` на IP сервера.
3. Сессии и `SITE_KEY` переносятся → водителей не выкинет, ссылку заново слать не нужно.
4. Проверить вход, `https://autozxc.app/healthz`, затем Replit: Unpublish.

## Грабли, на которые уже наступили

- У Replit **превью и опубликованный сайт — разные базы**. Сброс в превью не трогает прод.
- Replit-агент не может менять production-базу.
- Номер версии состояния `v` только растёт (и при сбросе), `/api/state` отдаёт полное состояние при любом несовпадении `v` — не ломать. Открытая шторка при этом не перерисовывается — см. План A.3.
- iPhone: поле со шрифтом < 16px → автозум и «съехавшая» страница (исправлено в v31, не ломать).
- Иконка «На экран Домой» на iPhone хранит cookie отдельно от Safari (manifest `start_url` с ключом это решает).
