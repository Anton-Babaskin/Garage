# Гараж v22 — запуск на Replit

Сайт учёта машин: RU + TR, вход по PIN, общий журнал для водителей и руководства.
Инструкция для агента Replit — в **`replit.md`** (он читает её сам).

---

## 1. Загрузить проект (5 мин)

1. Replit → **Create App** → шаблон **Node.js** → название `garage`.
2. Удалить файлы шаблона (`index.js` и т.п.).
3. Распаковать `garage-v22.zip`, в дереве файлов Replit: **⋮ → Upload folder** → выбрать содержимое папки `garage` (или перетащить файлы мышкой). В корне должны быть `server.js`, `core.js`, `public/`, `replit.md`, `.replit`.
4. Shell: `npm install && npm test` → в конце **«✓ Всё в порядке, можно публиковать»**.

## 2. База и секреты

1. Вкладка **Database** → создать **PostgreSQL**. Replit сам добавит `DATABASE_URL`.
2. **Secrets** → добавить `ADMIN_PIN` = твои 6 цифр (вход «Антон»). Не `123456` и не одинаковые цифры.

> ⚠ Без базы опубликованный сайт не запустится — так задумано: иначе журнал стирался бы при каждом перезапуске.

## 3. Публикация

1. **Deploy / Publish** → тип **Reserved VM** (всегда включён, один экземпляр — так правильно для этого сервера).
2. Команды подтянутся из `.replit` (build `npm install`, run `node server.js`). Порт 8080.
3. Проверь в настройках деплоя, что `DATABASE_URL` и `ADMIN_PIN` там есть.
4. Publish → адрес вида `https://garage-xxx.replit.app` (можно привязать свой домен).

✅ Проверка: открыть `https://…replit.app/healthz` → `{"ok":true,"v":1}`.

## 4. Первый запуск в работу

1. Открыть сайт **в новой вкладке браузера** → «Антон» → `ADMIN_PIN`.
2. Задать PIN каждому: имя вверху справа → **Новый PIN** (водителям 4 цифры, руководству 6).
3. Внести машины: Машины → машина → **Внести данные** (пробег, паркинг, ключи).
4. Разослать водителям текст ниже. Попросить добавить сайт на главный экран.

## 5. Пробег вручную

- **Первый раз:** Машины → машина → «Внести данные».
- **Исправить потом:** Машины → машина → **«Исправить пробег»** → новое число + причина. Можно больше или меньше. Исправление остаётся в журнале («Антон исправил пробег · BMW · было … → стало …»). Работает, когда машина стоит на паркинге.

## 6. Как просить агента Replit

Выбери модель Claude. Первое сообщение после загрузки — вставь как есть:

```
Прочитай replit.md полностью. Это рабочий сайт, им пользуются люди каждый день.
Ничего не меняй сейчас. Ответь в 5 пунктах: как устроены данные, что тебе запрещено,
где менять тексты и перевод, как проверять перед публикацией, что делать с просьбой «поменяй пробег».
```

Дальше — по шаблону:

```
Задача: <что нужно, одним-двумя предложениями>.
Как должно выглядеть: <для кого — водитель / руководитель, телефон / ПК>.
Правила: маленькая правка, оба языка (RU и TR), APP_VERSION +1, запись в CHANGELOG, npm test зелёный. Покажи, какие файлы менял.
```

Не проси агента «поменять пробег / PIN / номер» — это делается в самом сайте (агент тоже так ответит).

## 7. Отдать проект Claude (если сложное)

Replit → **⋮ → Download as zip** → прислать архив в чат. Или подключить GitHub (Git → Connect) и дать ссылку на репозиторий.
Данные журнала: на сайте Водители → **Сохранить копию** (JSON).

## 8. Если что-то не так

| Симптом | Что делать |
|---|---|
| Сайт не стартует, в логах «без DATABASE_URL» | Подключить PostgreSQL → Publish заново |
| Ошибка SSL к базе в логах | Secrets → `PGSSL_NOVERIFY=1` → Redeploy |
| Во встроенном превью Replit не входит | Нормально, открыть в новой вкладке |
| Агент что-то сломал | Откатить к прошлому checkpoint в чате агента → Redeploy. Данные не пострадают |
| «Слишком много попыток» | Подождать 15 мин или задать человеку новый PIN |

## 9. Безопасность (уже включено)

PIN в виде scrypt-хэша · блок после 5 ошибок · cookie HttpOnly/Secure/SameSite · CSP `script-src 'self'` · роли проверяет сервер · автор и время записи — с сервера · копии раз в сутки (60 шт.) · журнал действий в логах (`audit`).
Экран входа показывает имена — если нужно скрыть сайт целиком, включи в Replit приватный деплой (если есть в тарифе) или поставь Cloudflare Access на свой домен.

## Свой сервер вместо Replit

`deploy/docker/` (Docker + Caddy с HTTPS) и `deploy/garage.service` (systemd). Без `DATABASE_URL` данные хранятся в файлах `./data`.

## Текст для водителей

**RU**
> Теперь машины отмечаем в приложении «Гараж»: <ссылка>
> 1. Откройте ссылку, нажмите своё имя, введите PIN (4 цифры).
> 2. Добавьте на главный экран: Поделиться → «На экран Домой».
> 3. Берёте машину — нажмите её и «Взять». Поставили — зелёная кнопка «Поставить на паркинг»: паркинг, пробег, где ключи.
> PIN никому не сообщайте. Забыли — пишите мне.

**TR**
> Araçları artık «Garaj» uygulamasında işaretliyoruz: <bağlantı>
> 1. Bağlantıyı açın, adınıza dokunun, PIN kodunuzu girin (4 hane).
> 2. Ana ekrana ekleyin: Paylaş → «Ana Ekrana Ekle».
> 3. Aracı alırken araca dokunup «Al»a basın. Park edince yeşil «Otoparka bırak» düğmesi: otopark, kilometre, anahtar nerede.
> PIN kodunuzu kimseyle paylaşmayın. Unutursanız bana yazın.
