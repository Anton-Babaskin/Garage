---
name: Доступность браузерного тестирования
description: Расхождение между инструкцией тестирования и доступными видами подагентов.
---

Проверять фактический результат запуска браузерного подагента, а не считать его доступным только по инструкции.

**Why:** В этой среде документированный вид `testing` сначала отклонялся с `Unknown config kind: testing`, а позднее запускался успешно без изменения вызова. Доступность инструмента может меняться; прежний отказ не является постоянным ограничением или результатом теста приложения.

**How to apply:** Сначала сверять актуальную инструкцию и результат текущего запуска. Если вид снова отклонён, не повторять тот же вызов и не объявлять тесты пройденными; использовать доступный браузер на изолированном временном хранилище, не изменяя реальные учётные данные и не добавляя зависимости приложению ради обхода ограничения.
