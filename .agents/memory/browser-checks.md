---
name: Доступность браузерного тестирования
description: Расхождение между инструкцией тестирования и доступными видами подагентов.
---

Проверять фактический результат запуска браузерного подагента, а не считать его доступным только по инструкции.

**Why:** В этой среде документированный вид `testing` был отклонён с `Unknown config kind: testing`. Это не результат теста приложения. Проверка через установленный Chromium состоялась без новых зависимостей приложения.

**How to apply:** Сначала сверять актуальную инструкцию. Если вид снова отклонён, не повторять тот же вызов и не объявлять тесты пройденными; использовать доступный браузер на изолированном временном хранилище, не изменяя реальные учётные данные.
