---
name: Доступность браузерного тестирования
description: Доступность браузерного тестирования, Secure-cookie на loopback и очистка конфигурации после временных фикстур.
---

Проверять фактический результат запуска браузерного подагента, а не считать его доступным только по инструкции.

**Why:** В этой среде документированный вид `testing` сначала отклонялся с `Unknown config kind: testing`, а позднее запускался успешно без изменения вызова. Доступность инструмента может меняться; прежний отказ не является постоянным ограничением или результатом теста приложения.

**How to apply:** Сначала сверять актуальную инструкцию и результат текущего запуска. Если вид снова отклонён, не повторять тот же вызов и не объявлять тесты пройденными; использовать доступный браузер на изолированном временном хранилище, не изменяя реальные учётные данные и не добавляя зависимости приложению ради обхода ограничения.

На HTTP loopback проверять защищённые cookie-запросы из самой страницы, а не считать ответ Playwright APIRequestContext эквивалентным браузеру.

**Why:** При проверке закрытого manifest `context.request.get()` получил 404, хотя в той же браузерной сессии `fetch(..., {credentials:'same-origin'})` вернул 200. API-клиент, вероятно, не отправил Secure-cookie по HTTP `127.0.0.1`; браузер принимает loopback как доверенный контекст. Это был ложный вывод о неработающем маршруте.

**How to apply:** При неожиданном отказе авторизованного API на изолированном HTTP-сервере сверить способ запроса и проверить его через `page.evaluate`/браузерную сеть. Не убирать Secure и не ослаблять cookie ради теста; не выводить значения cookie в отчёт.

Для одноразовых тестовых изображений предпочитать уже имеющийся Node.js, не добавлять языковой runtime ради генератора.

**Why:** Один запуск Python для синтетического PNG автоматически добавил `python-base` в `.replit`, а временный браузерный сервер — отдельное отображение порта. Это ненужные изменения окружения рабочего Node.js-приложения, хотя генератор и хранилище были в `/tmp`.

**How to apply:** После остановки временного тестового сервера проверить diff `.replit` и убрать только добавленные проверкой runtime/порты, сохранив настройки основного Garage. Для фикстур достаточно Node Buffer/zlib; не оставлять тестовый сервер работающим.
