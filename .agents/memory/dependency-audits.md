---
name: Аудит зависимостей
description: Почему аудит находит зависимости вне npm-графа работающего сервера.
---

При исправлении уязвимостей проверять оба lockfile, а не только npm-зависимости сервера. Синхронизировать pnpm-граф с существующими workspace-пакетами, сохраняя библиотеки, которые ещё есть в проекте.

**Why:** Аудит учитывал устаревшие записи удалённых приложений в pnpm-lockfile, хотя работающий сервер устанавливает только pg через npm. Чистый npm-аудит сам по себе не подтверждал устранение всех находок.

**How to apply:** Сначала сопоставить записи lockfile с актуальными манифестами, затем обновить нужные зависимости и подтвердить результат общим аудитом. Не добавлять отсутствующие серверу пакеты только ради их обновления.
