# Журнал версий

Формат: `vN — дата — что изменилось`. Новая строка сверху. Номер = `APP_VERSION` в `public/ui.js`.

- v34 — 2026-11-05 — Android: в «Поставить на паркинг» две кнопки фото — «Сфотографировать» (сразу камера) и «Из галереи». На iPhone без изменений: одна кнопка «Фото места» с системным меню. RU/TR.
- v33 — 2026-11-04 — водитель может держать несколько машин одновременно: брать вторую/третью и принимать передачу, даже если у него уже есть машина. «Мой экран» показывает все его машины с кнопками «Поставить»/«Передать» и ниже список «Взять ещё машину». RU/TR, журнал не изменён.
- v32 — 2026-11-04 — убраны все ограничения пробега: любое целое число, можно меньше прошлого, без лимита 2 000 000 и проверки скачка 3 000 км; подсказки под полем остались, но ничего не блокируют. Старые события и журнал не изменены.
- v31 — 2026-11-02 — мобильные формы подстраиваются под видимую область с клавиатурой, поля без автозума, кнопки с safe-area и защита от горизонтального смещения; Enter скрывает клавиатуру. После подтверждённых действий — крупная зелёная галочка, ключи у водителя отмечены оранжевым, версия видна только руководству. RU/TR, логика учёта и рабочие данные не изменены.
- v30 — 2026-11-02 — исправлена парковка с неизменённым старым показанием вне диапазона: поездку можно закрыть, не исправляя пробег и историю автоматически. Новые ошибочные показания по-прежнему запрещены; проверки клиента и сервера согласованы.
- v29 — 2026-11-02 — в окнах «Взять» и «Поставить на паркинг» подставляется последний пробег; при фокусе число выделяется целиком. Убрана верхняя дублирующая плашка выезда, добавлены RU/TR-подсказки; неизменённый пробег при парковке предупреждает, но не блокирует сохранение.
- v28 — 2026-11-02 — фото места при парковке отдельно от журнала, просмотр в карточке и на весь экран; проверка нового пробега и скачков свыше 3 000 км; цветные точки статуса; сброс одной машины с сохранением журнала и общий сброс только Антоном с обязательной копией до сброса. RU/TR, пароли и сессии сохранены; production-данные автоматически не меняются.
- v27 — 2026-10-27 — закрыт доступ к страницам и API без SITE_KEY, cookie доступа или действующей сессии; динамический manifest для iPhone, безликий вход по логину/паролю, список людей только после входа, запрет индексации. PIN Антона, пароли, журнал и production-база не изменены.

- v25 — 2026-10-27 — настроен post-merge: установка npm-зависимостей из lockfile и запуск тестов; удалён вызов шаблонной миграции БД. Логика сайта и данные без изменений.

- v23 — 2026-10-26 — вход по паролю для водителей, Руководителя и Дарьи; руководство задаёт пароль одним полем, старый PIN действует до его назначения. Вход Антона и ADMIN_PIN без изменений.
